<h1 align="center">Scan Host (Domain & IP Scanner)</h1>
<p align="center">It’s a tool for scanning domains and IPs, letting you check things like ping, HTTP status, IP details, server location, and a bunch of other useful info.
It also has an extra feature that can detect whether a site’s traffic is inside Iran or international, and even tells you if the traffic is half-price or not (this part of the tool only works for Iran’s internet traffic).</p>
<p align="center">This project is purely experimental and didn’t have any specific goal behind it. I decided to publish it simply because the final result looked interesting, and I thought maybe it might be useful for someone or they might just enjoy it. Once I chose to release it, I spent a lot of time on the UI, and this is what it turned into. My goal was to make it look and feel like a real scanner.
Since this project is unique to me and I’ve spent a lot of time on it, I won’t be releasing it as open-source; but I’ll provide a demo link so anyone who wants can check it out or use it—no problem. Enjoy!</p>
<p align="center">Note: There might still be a few small bugs here and there. If you notice any, please report them so I can fix them.</p>

<h1 align="center">Scan Host (اسکنر آیپی و دامنه)</h1>
<p align="center">این یک ابزار برای اسکن کردن دامنه‌ها و IPهاست. باهاش می‌تونی چیزهایی مثل پینگ، وضعیت HTTP، جزئیات IP، محل سرور و یه سری اطلاعات کاربردی دیگه رو چک کنی.
یه قابلیت اضافه هم داره که تشخیص می‌ده ترافیک یه سایت داخلیه یا بین‌المللی، و حتی می‌گه ترافیکش نیم‌بها هست یا نه. (این بخش فقط برای اینترنت ایران کار می‌کنه.)</p>
<p align="center">این پروژه کاملاً تمرینی بود و هدف خاصی پشتش نبود. فقط چون نتیجه‌ی نهایی جالب از کار دراومد، تصمیم گرفتم منتشرش کنم؛ شاید برای کسی مفید باشه یا ازش ایده بگیره. وقتی تصمیم گرفتم منتشرش کنم، وقت زیادی روی رابط کاربریش گذاشتم و در نهایت به همین چیزی تبدیل شد که الان هست. هدفم این بود که ظاهر و حس یه اسکنر واقعی رو داشته باشه.
از اون‌جایی که این پروژه برام خاصه و کلی وقت روش گذاشتم، قرار نیست به‌صورت متن‌باز منتشرش کنم؛ ولی یه لینک دمو می‌ذارم که هر کسی خواست بتونه تستش کنه یا ازش استفاده کنه—بدون هیچ مشکلی. امیدوارم خوشتون بیاد!</p>
<p align="center">نکته: ممکنه هنوز چندتا باگ کوچیک توی پروژه باقی مونده باشه. اگر چیزی به چشم‌تون خورد، لطفاً گزارشش کنید تا بتونم درستش کنم.</p>
